# Installer Portal — Desktop

## Visual system
Dark mode is deliberate and distinct from the consumer experience.
It should feel professional, premium and operational.

Suggested shell:
- left navigation rail
- top utility bar
- primary work area
- dark charcoal/slate surfaces
- green used only for confirmed/on-track/available/positive metrics

## Navigation
- Dashboard
- Jobs
- Schedule
- Customers
- Messages
- Documents
- Performance
- Payments
- Resources
- Support

Do not over-nest navigation.

## Dashboard
Top row:
- Active/new jobs
- Upcoming installs
- Awaiting action
- Completed this month
- rating/performance if relevant

Main body:
- Today’s installs / jobs
- next job card
- performance snapshot
- alerts requiring action

## Jobs
Filters:
- New
- Accepted
- Scheduled
- In progress
- Completed

Job row should show:
- customer
- suburb
- package
- requested/preferred date
- status
- primary action

## Job detail / site pack
Tabs:
- Overview
- Site
- System
- Documents
- Messages
- Activity

High-priority information:
- address
- customer contact
- system package
- install date/window
- access notes
- roof/site imagery
- switchboard notes
- approvals/checklist
- required documents

## Schedule
Week view first.
Allow crew assignment and status.
Avoid overly complex drag/drop until necessary.

## Performance
Use only metrics that drive installer behaviour:
- jobs completed
- on-time rate
- first-time pass / defect rate
- customer rating
- response time
- revenue/payouts
