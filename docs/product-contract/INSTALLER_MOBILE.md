# Installer Portal — Mobile

## Purpose
The mobile installer app is for field execution, not business administration.

## Bottom navigation
- Today
- Jobs
- Messages
- More

## Today
- next job
- route/time
- status
- customer contact shortcut
- site pack shortcut

## Job detail
Above the fold:
- customer
- address
- install time
- system
- current status
- Start / Update status CTA

Sections:
- Site notes
- Access
- System
- Checklist
- Photos
- Documents
- Customer contact

## Status flow
Simple sequential states:
1. En route
2. On site
3. Installation in progress
4. Final checks
5. Complete

Each status change records timestamp and can trigger customer notification.

## Field constraints
- large tap targets
- high contrast
- usable outdoors
- resilient loading states
- photo upload from camera
- offline-friendly queueing if feasible
