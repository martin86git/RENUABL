# Consumer Mobile UX

## Principle
Mobile is the primary acquisition and transaction surface. It must feel native, not like a compressed desktop site.

## Shell
- 16–20px horizontal padding.
- Sticky bottom CTA for high-intent flow steps where useful.
- Bottom nav appears after account creation / post-install, not necessarily during initial guided flow.
- Use full-width cards with generous vertical rhythm.

## Homepage
- Wordmark
- headline
- short supporting line
- address input
- mascot
- Ask RENUABL prompt
Everything important should be visible without a long scroll.

## Progress
Use 4–7 small dots/line rather than verbose step labels at top.
Display current step title below.

## Recommendation
Stack system items vertically.
One recommended state.
Allow “Why this?” expansion.

## Installer match
One installer.
No comparison table.
Show trust metadata in small rows.
Secondary “View alternatives” link only.

## Calendar
Use native-feeling month calendar and tappable time pills.
One selected state.

## Payment
Use Apple Pay / Google Pay / card prominently.
Keep terms short and clear.

## Ask RENUABL
Use a compact bottom prompt/card at moments of uncertainty.
Do not show it on every screen if it competes with the primary CTA.
